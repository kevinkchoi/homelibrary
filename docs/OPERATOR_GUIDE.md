# 운영자 안내 — 사용자 초대하기 (personal 모드)

개인 서재 서버(`LIBRARY_MODE=personal`)에서 새 사람을 들이는 방법을 정리합니다.
가족 공용 서버(`family`)는 가입이 닫혀 있고, 관리자가 [관리] → [사용자 관리]에서 가족 계정을 만듭니다. 이 문서의 내용은 해당하지 않습니다.

> 화면에 나오는 단추·메뉴 이름은 코드와 대조해 적었습니다(2026-11-27). 화면 글자를 바꾸면 이 문서도 같이 고쳐 주세요.

---

## 먼저 정할 것: 어느 쪽으로 들이나

| 초대받는 사람이… | 쓰는 코드 | 가입하면 |
|---|---|---|
| **자기 도서관을 새로 만든다**(친구·지인 — 책을 따로 관리) | **사이트 초대 코드**(`.env`의 `SIGNUP_INVITE_CODE`) | 그 사람만의 새 도서관이 생기고 그 사람이 **주인** |
| **이미 있는 도서관에 함께 들어간다**(가족 — 같은 책을 함께 봄) | **도서관 초대 코드**(`lib-xxxx-xxxx`) 또는 주인이 계정을 직접 만들어 줌 | 그 도서관의 **멤버**(권한은 주인이 정함) |

- 지금은 **한 사람이 한 도서관에만** 속합니다. 이미 가입한 사람이 다른 도서관으로 옮기거나 두 곳에 함께 속할 수는 없습니다.
  옮기려면 새 도서관에서 계정을 새로 만들어야 합니다(앞으로 할 일).
- 메일 인증이나 비밀번호 찾기는 없습니다. 비밀번호를 잊으면 그 도서관의 주인이나 공동 관리자가 **[비밀번호 재설정]**으로 바꿔 줍니다.

---

## 1. 새 도서관을 만들 사람 초대 — 사이트 초대 코드

### 초대받는 사람이 하는 일
1. 휴대폰이나 컴퓨터로 서비스 주소(예: `https://homelibrary.kr`)를 엽니다.
2. 로그인 화면에서 **[초대 코드로 가입하기]**를 누릅니다(바로 가려면 주소 뒤에 `/register`).
3. **초대 코드**, **아이디**(3자 이상), **비밀번호**(6자 이상)를 넣습니다. 이메일은 넣지 않아도 됩니다.
4. 가입하면 자동으로 로그인되고 **환영 안내**가 한 번 뜹니다. 이때 「<아이디>의 도서관」이 생기고, 가입한 사람이 그 도서관의 **주인**이 됩니다.

### 알려 주면 좋은 것
- **AI 기능**(표지 사진으로 책 넣기, 새책 추천)을 쓰려면 ☰ → **[내 설정]**에 **자기 Claude API 키**를 넣어야 합니다. 키가 없으면 이 메뉴가 보이지 않습니다.
  바코드 스캔, 검색, 서평 같은 나머지 기능은 키 없이 모두 됩니다.
- 사용법은 ☰ → **[도움말 · 의견]**에 있습니다. 불편한 점은 그 안의 **[의견 보내기]**로 알려 달라고 하면 운영자의 **[의견함]**과 텔레그램으로 옵니다.

### 사이트 초대 코드는 "공용 열쇠"다
- 코드를 아는 사람은 **누구나 몇 번이든** 가입할 수 있습니다. 1회용이 아니고, 누가 이 코드로 가입했는지 따로 기록하지 않습니다.
- 너무 퍼졌다 싶으면 코드를 바꿉니다. 이미 가입한 사람에게는 영향이 없습니다.

### 코드를 바꾸는 법 (서버에서)
```bash
cd <설치 폴더>
# .env 의 SIGNUP_INVITE_CODE= 값을 새 값으로 바꾼다 (예: openssl rand -hex 4 로 만든 글자를 섞어서)
nano .env
# API만 다시 띄운다 — compose가 .env 값이 바뀐 것을 보고 컨테이너를 새로 만든다
docker compose up -d homelibrary-api
```
- ⚠️ `update.sh`로는 반영되지 않습니다. `update.sh`는 **GitHub에 새 커밋이 있을 때만** 다시 빌드하므로, `.env`만 바꾼 경우에는 위 명령을 써야 합니다.
- 바뀌었는지 확인하려면 **옛 코드로 가입이 거절되는지** 보면 됩니다. 코드 값 자체는 로그나 문서에 남기지 않습니다.
- 값을 비우면(`SIGNUP_INVITE_CODE=`) 새 도서관 가입이 **닫힙니다**. 도서관 초대 코드(`lib-…`)로 멤버가 들어오는 것은 그대로 됩니다.

## 2. 내 도서관에 함께 들어올 사람 — 멤버 넣기

로그인한 뒤 ☰ → **[우리 도서관]**에서 합니다. 이 일은 **주인**과 **공동 관리자**만 할 수 있습니다.

### 방법 A. 계정을 직접 만들어 주기 (가장 확실)
1. **멤버 추가 — 직접 만들어 주기** 칸에 아이디, 비밀번호, 이메일(선택)을 넣고 권한을 고른 뒤 **[추가]**를 누릅니다.
2. 만든 아이디와 비밀번호를 그 사람에게 알려 줍니다.
3. 그 사람은 로그인한 뒤 ☰ → **[내 설정]**에서 비밀번호를 자기 것으로 바꿉니다.

부모님처럼 가입 화면을 다루기 어려운 분께 좋습니다.

### 방법 B. 도서관 초대 코드 보내기
1. **도서관 초대 코드** 칸에서 "○○으로 들어오게"(권한)를 고르고 **[초대 코드 만들기]**를 누릅니다.
2. `lib-xxxx-xxxx` 코드를 **[복사]**해서 메신저로 보냅니다.
3. 받은 사람은 **[초대 코드로 가입하기]**에서 이 코드를 넣고 아이디와 비밀번호를 정합니다. 사이트 초대 코드는 필요 없습니다.
   가입하면 바로 이 도서관의 멤버가 됩니다.
4. 다 들어왔으면 **[끄기]**로 코드를 막아 둡니다. 코드가 남아 있으면 누구든 그 권한으로 들어올 수 있습니다.
   - **[새 코드로 바꾸기]**: 옛 코드는 곧바로 무효가 됩니다.
   - 코드로 들어올 사람의 권한은 코드마다 하나입니다. 다른 권한으로 들이려면 고르고 다시 만듭니다.

### 권한 (멤버마다 정하고 나중에도 바꿀 수 있음)

| 권한 | 책 보기·검색 | 책 넣기·고치기·지우기, 서평, 가져오기 | 멤버·초대 코드·도서관 이름 관리 |
|---|---|---|---|
| **주인** | ✅ | ✅ | ✅ (주인은 바꾸거나 뺄 수 없음) |
| **공동 관리자** | ✅ | ✅ | ✅ |
| **편집** | ✅ | ✅ | — |
| **보기만** | ✅ | — (단추가 보이지 않고, 서버도 403으로 막음) | — |

- **보기만** 권한은 서점에서 "이미 있는 책인지"만 확인하면 되는 가족이나 아이에게 맞습니다.
- 멤버 줄에서 권한 목록, **[비밀번호 재설정]**, **[빼기]**를 쓸 수 있습니다.
- **[빼기]**를 누르면 그 사람의 계정이 지워집니다. 그 사람이 넣은 책은 **도서관에 남습니다**(도서관 전체의 책이므로).

## 3. 운영자가 보는 것 / 할 수 있는 것

운영자(`is_admin`)는 ☰ → **[관리]**에서 운영자 카드 두 개를 봅니다.

- **도서관 관리 (운영자)**
  - 보이는 것: 도서관 이름, 주인 아이디, 멤버 아이디와 수, 책 수, 만든 날.
  - 보이지 않는 것: **이메일, 책 제목, 서평**. 운영자도 남의 도서관 책을 열어 보거나 빼낼 수 없게 만들었습니다.
  - **말썽 사용자 정리**
    - 멤버 이름 옆 **✕**(「이 사용자만 삭제」): 그 계정만 지웁니다. 그 사람이 넣은 책은 도서관에 남습니다.
    - **[도서관 삭제]**: 도서관을 통째로 지웁니다(멤버 계정, 책, 표지 모두). 되돌릴 수 없으니 먼저 그 줄의 **[백업]**을 받아 두세요.
    - 주인 계정과 운영자 자신의 도서관은 이 화면에서 지울 수 없습니다.
  - **암호화 백업·복구**: **[⬇ 전체 백업 내려받기]**, 도서관별 **[백업]**, **[⬆ 백업으로 복구…]**.
    받은 파일은 서버의 `SITE_BACKUP_SECRET` 없이는 열 수 없고, 이 화면의 복구로만 되살립니다.
    복구할 때 같은 도서관이 아직 있으면 그 도서관을 백업 시점으로 되돌립니다. 그 뒤에 넣은 책은 사라집니다.
    `SITE_BACKUP_SECRET`을 잃으면 백업도 잃습니다. 서버 밖에 따로 보관하세요.
- **의견함 (운영자)**: 사용자가 보낸 의견을 보고 처리 상태와 답을 남깁니다. 보낸 사람은 [내가 보낸 의견]에서 답을 봅니다.
  `TELEGRAM_BOT_TOKEN`·`TELEGRAM_CHAT_ID`를 넣어 두면 새 의견이 텔레그램으로도 옵니다. 첫 줄에 `(공개 서비스)` / `(가족 서버)`로 어느 서버에서 왔는지 표시됩니다.

## 4. 자주 묻는 것

- **"가입 화면에서 초대 코드가 틀렸다고 나와요"**: 사이트 코드가 바뀌었거나, 도서관 코드가 **[끄기]**·**[새 코드로 바꾸기]**로 무효가 된 경우입니다. 새 코드를 다시 받으세요.
- **"화면이 예전 그대로예요"**: 앱이나 브라우저를 완전히 닫았다가 다시 여세요(서비스워커가 옛 화면을 붙잡고 있는 경우).
- **"시도가 너무 많습니다"라고 나와요**: 로그인·가입은 한 사람(접속 주소)당 1분에 10번쯤까지입니다(비밀번호 무작위 대입 방지). 1분쯤 기다렸다 다시 하세요.
- **"가족이 따로 가입해 버렸어요"**: 그 계정은 별도 도서관의 주인이라 내 도서관으로 옮길 수 없습니다. 운영자가 **[도서관 관리]**에서 빈 도서관을 지우고, 내 도서관에서 방법 A나 B로 다시 들이세요.
