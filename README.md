# 📚 Home Library

**집에 있는 책을 휴대폰으로 관리하는 개인 도서관 프로그램입니다.**

책이 많아지면 서점에서 "이 책, 집에 있던가?"가 헷갈립니다. 같은 책을 두 번 사기도 하고, 있는 줄 알았던
책이 없기도 합니다. Home Library는 그 질문에 바로 답하려고 만들었습니다.

서점에서 책 뒤표지의 **바코드를 휴대폰으로 비추면**, 이미 가진 책인지와 **집 어느 책꽂이에 있는지**를
그 자리에서 알려줍니다.

- **바로 써 보기**: **https://homelibrary.kr** — 초대 코드로 가입하면 나만의 서재가 생깁니다
- **내 서버에서 운영하기**: 이 저장소를 Docker로 띄우면 됩니다 → [직접 운영하기](#직접-운영하기)

## 주요 기능

### 🛑 중복 구매 방지
책을 넣으려 하면 이미 서재에 있는지 **즉시 경고**하고, 어느 책꽂이에 있는지 함께 보여줍니다.
- **ISBN이 같으면** 확실한 중복, **제목만 같으면** 판이 다를 수 있으니 참고용으로 나눠 표시
- ISBN 10자리/13자리, 하이픈 유무가 달라도 같은 책으로 알아봅니다
- 일부러 여러 권 두는 책은 **[이건 다른 책입니다]** 로 표시하면 다시 묻지 않습니다

### 📷 책 넣기 — 세 가지 방법
| 방법 | 이렇게 쓰세요 |
|---|---|
| **바코드 스캔** (가장 빠르고 정확) | 책 뒤표지의 줄무늬 바코드를 비추면 제목·저자·출판사·표지가 자동으로 채워집니다. 여러 권을 연속으로 찍어 한꺼번에 등록할 수도 있습니다 |
| **표지 사진** | 바코드가 없는 오래된 책은 표지를 찍으면 AI(Claude)가 제목과 저자를 읽고 나머지를 찾아 채웁니다 |
| **직접 입력** | ISBN만 넣어도 나머지가 채워집니다 |

카메라를 쓸 수 없는 환경에서는 바코드 **사진 한 장**으로 자동 전환되고, 가까이 대면 초점이 안 맞는 큰
휴대폰을 위해 **줌·초점·플래시** 단추가 있습니다(기기가 지원할 때만 보입니다).

### 🔍 찾기
- 제목·저자·출판사·번역자·ISBN을 **한 칸에서** 검색
- **띄어쓰기를 무시**합니다 — `작은정원`으로 `작은 정원`을 찾습니다
- **외국 저자는 로마자로도** — `Laurent`로 `로랑`을, `Robert`로 `로버트`를 찾습니다(소리로 맞춤)
- 제목·저자·출판사·카테고리·**책꽂이(여러 개 동시 선택)** 로 거르기, 원하는 기준으로 정렬
- 휴대폰에서는 카드 목록, 넓은 화면에서는 표로 보입니다

### ✍️ 서평
책마다 서평을 남길 수 있습니다. A4 몇 쪽 분량도 넉넉히 들어가고, **마크다운**(제목·굵게·목록 등)을
서식 단추로 쉽게 쓸 수 있습니다.

### ✨ 새책 추천
내 서재에 많은 분야의 신간·베스트셀러를 모아, **이미 가진 책은 빼고** AI가 내 서재의 결에 맞는 것을
골라 **추천 이유 한 줄**과 함께 보여줍니다. 하루에 한 번 새로 만듭니다.

### 🗂 정리
- **엑셀/CSV 내보내기·가져오기** — 목록을 엑셀에서 고쳐 다시 가져오면 그대로 반영됩니다(왕복 편집)
- **카테고리 정리** — 제각각인 분류를 권수를 보며 합칩니다
- **책꽂이 일괄 지정** — 여러 권을 골라 한 번에 자리를 정합니다
- **서재 점검** — 이미 들어간 중복, 표지가 깨진 책을 찾아 정리합니다

### 👪 가족·친구와 함께 (개인 서재 서버)
가입하면 **나만의 도서관**이 생기고 내가 **주인**이 됩니다. 가족·친구를 멤버로 넣으면 같은 책 목록을 함께 봅니다.
- 멤버 넣기: **아이디·비밀번호를 직접 만들어 주거나**, `lib-`로 시작하는 **도서관 초대 코드**를 나눠 줍니다
- 멤버마다 권한을 정합니다: **공동 관리자**(멤버 관리) / **편집**(책 넣기·고치기·지우기) / **보기만**
- 다른 도서관의 책은 서로 보이지 않습니다

### ❓ 도움말 · 의견 보내기
처음 로그인하면 **환영 안내**가 무엇부터 하면 되는지 알려 주고, [도움말]에 자세한 사용법이 있습니다.
불편한 점이나 바라는 기능은 **[의견 보내기]**로 운영자에게 보내고, 운영자의 답과 처리 상태를 [내가 보낸 의견]에서 봅니다.

### 📱 앱처럼 쓰기
휴대폰 브라우저에서 **홈 화면에 추가**하면 아이콘을 눌러 앱처럼 전체 화면으로 씁니다
(아이폰은 Safari → 공유 → 홈 화면에 추가, 안드로이드는 Chrome → ⋮ → 홈 화면에 추가).
화면의 **[앱 설치 안내]** 가 기기에 맞는 방법을 알려줍니다.

## 사용 방법 (homelibrary.kr)

1. **가입하기** — 로그인 화면의 [초대 코드로 가입하기]에서 초대 코드, 아이디, 비밀번호를 넣습니다.
   이메일은 선택입니다. 가입하면 **나만의 도서관**이 생깁니다 — 다른 도서관의 책은 보이지 않고,
   내 책도 다른 도서관에 보이지 않습니다. 가족·친구에게서 받은 **도서관 코드**(`lib-…`)로 가입하면
   그 도서관에 함께 들어갑니다.
2. **책 넣기** — 왼쪽 위 ☰ 메뉴 → [바코드 스캔]에서 책을 연속으로 찍어 보세요. 책꽂이 위치를 함께
   적어 두면 나중에 "어디 있지?"가 해결됩니다.
3. **서점에서** — [새책 추가]에서 바코드를 비추면, 이미 가진 책이면 바로 경고가 뜹니다.
4. **AI 기능 켜기(선택)** — 표지 사진 인식과 새책 추천은 Anthropic의 Claude를 씁니다.
   ☰ → [내 설정]에 **내 Claude API 키**를 넣으면 켜집니다(키는 [console.anthropic.com](https://console.anthropic.com/settings/keys)에서
   만들고, 사용료는 내 Anthropic 계정에 청구됩니다). 키는 서버에 암호화해서 보관하고 다시 보여주지 않습니다.
   키가 없어도 바코드·ISBN·직접 입력·검색은 모두 됩니다.
5. **함께 쓰기** — ☰ → [우리 도서관]에서 멤버를 만들거나 초대 코드를 만들고, 멤버마다 권한을 정합니다.
6. **비밀번호** — [내 설정]에서 바꿀 수 있습니다. 잊어버렸다면 멤버는 도서관 주인에게, 주인은 운영자에게
   요청하세요(아직 메일로 찾는 기능은 없습니다).
7. **도움말·의견** — ☰ → [도움말 · 의견]. 바라는 기능이나 불편한 점을 운영자에게 보낼 수 있습니다.

## 직접 운영하기

Docker와 Docker Compose만 있으면 됩니다. 나머지는 모두 컨테이너 안에 들어 있습니다.

```bash
git clone https://github.com/kevinkchoi/homelibrary.git
cd homelibrary
cp .env.example .env
# .env를 열어 POSTGRES_PASSWORD, DATABASE_URL의 비밀번호, JWT_SECRET을 바꿉니다
#   (예: openssl rand -hex 32)
docker compose up -d --build
```

브라우저에서 `http://<서버 주소>:8080`을 열고 **처음 가입하는 계정이 관리자**가 됩니다.

### 두 가지 운영 형태

`.env`의 `LIBRARY_MODE` 하나로 정합니다.

| | `family` (기본값) | `personal` |
|---|---|---|
| 어떤 경우 | **가족이 한 서재를 함께** 쓸 때 | **여러 사람에게** 각자의 서재를 열어 줄 때 |
| 서재 | 모든 계정이 같은 책을 본다 | 가입자마다 **자기 도서관**. 주인이 멤버를 넣어 함께 본다 |
| 가입 | 첫 계정(관리자)만. 가족 계정은 관리자가 [사용자 관리]에서 만든다 | `SIGNUP_INVITE_CODE`(새 도서관) 또는 도서관 초대 코드(그 도서관의 멤버) |
| 운영자 | 가족 관리자 | 도서관 현황·**암호화 백업/복구**·말썽 사용자 삭제·의견함. **이메일·책 목록은 볼 수 없다** |
| AI 기능 | 서버 `.env`의 `ANTHROPIC_API_KEY` | 각 사용자가 [내 설정]에 넣은 자기 키 |

### 설정 (`.env`)

| 항목 | 설명 |
|---|---|
| `POSTGRES_*`, `DATABASE_URL` | DB 계정. 비밀번호를 꼭 바꾸세요 |
| `JWT_SECRET` | 로그인 토큰 서명용 긴 임의 문자열 |
| `WEB_PORT` | 화면이 열릴 포트 (기본 8080) |
| `LIBRARY_MODE` | `family` / `personal` |
| `SIGNUP_INVITE_CODE` | personal 모드의 가입 초대 코드. 비우면 가입이 닫힙니다 |
| `USER_KEY_SECRET` | 사용자 Claude 키를 암호화할 비밀값 (비우면 JWT_SECRET에서 만듦) |
| `SITE_BACKUP_SECRET` | 운영자 백업 파일을 암호화할 비밀값 — **잃으면 백업을 못 연다** (비우면 JWT_SECRET에서 만듦) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | 새 의견이 오면 운영자에게 텔레그램 알림 (선택) |
| `ALADIN_TTB_KEY` | 알라딘 Open API — 국내서 정보·표지·신간 (**권장**, 무료) |
| `KAKAO_REST_API_KEY` | 카카오 책 검색 — 국내서 보강 (선택) |
| `GOOGLE_BOOKS_API_KEY` | Google Books — 해외서 (선택, 없어도 동작) |
| `ANTHROPIC_API_KEY` | family 모드의 AI 기능 (선택) |
| `CONTAINER_PREFIX` | 같은 서버에 두 벌 띄울 때 컨테이너 이름 앞머리 |

키 발급 방법은 [docs/API_KEYS.md](docs/API_KEYS.md)에 있습니다.

### HTTPS가 필요합니다 (휴대폰에서 쓰려면)

휴대폰의 **실시간 바코드 스캔과 홈 화면 앱(PWA)** 은 브라우저 규칙상 HTTPS 주소에서만 됩니다.
`http://192.168.x.x` 같은 내부 주소에서는 바코드를 사진 한 장으로 찍는 방식만 됩니다.
Cloudflare Tunnel, Tailscale, 또는 리버스 프록시 + 인증서 중 편한 방법을 쓰세요 → [docs/INSTALL.md](docs/INSTALL.md)

### 백업

책 정보(DB)와 표지 이미지는 서로 다른 Docker 볼륨에 있어 **둘 다** 백업해야 합니다.

```bash
bash backup.sh     # DB 덤프 + 목록 CSV + 표지 이미지, 체크섬 검증까지
```

### 업데이트

```bash
bash update.sh     # GitHub의 새 버전과 비교해 바뀐 컨테이너만 다시 만든다
```

DB 구조가 바뀌는 업데이트는 컨테이너가 뜰 때 자동으로 적용됩니다(Alembic). 그 전에 `backup.sh`를 권합니다.

## 구성

| 컨테이너 | 역할 |
|---|---|
| `homelibrary-db` | PostgreSQL 16 |
| `homelibrary-api` | Python FastAPI — 인증, 책, 검색, 가져오기/내보내기, 스캔, 추천 |
| `homelibrary-web` | nginx + React(Vite) — 화면, `/api` 전달, 로그인 시도 횟수 제한 |

```
homelibrary/
├── backend/            FastAPI 앱, Alembic 마이그레이션
├── frontend/           React 화면, nginx 설정
├── docs/               설치·설계·API 키·표지 검색 문서
├── tools/              점검 도구 (CSS 검사, 격리 점검, 아이콘 생성 등)
├── docker-compose.yml
├── backup.sh / update.sh
└── .env.example
```

API와 데이터 모델은 [docs/DESIGN.md](docs/DESIGN.md)를 보세요.

## 보안

- personal 모드에서 사용자는 **다른 도서관의 책을 어떤 경로로도** 보거나 고치거나 지울 수 없습니다.
  번호로 남의 책을 열면 "없는 책"으로 답합니다. '보기만' 멤버는 책을 바꿀 수 없습니다.
- 운영자 화면에는 사용자의 **이메일·책 제목·서평이 나오지 않고**, 운영자는 남의 비밀번호를 바꿀 수 없습니다(계정 탈취 방지).
  운영자의 백업은 서버만 아는 키로 **암호화**되어 이 서버에서 복구하는 데만 쓰입니다.
  (서버 주인은 DB에 직접 접근할 수 있으므로, 이것은 "앱이 운영자에게 데이터를 보여 주는 길을 만들지 않는다"는 약속입니다)
- `tools/check_isolation.py`가 실제 API를 여러 사용자로 불러 확인합니다(관리자 계정을 주면 운영자 항목까지 74가지):
  ```bash
  python3 tools/check_isolation.py https://<주소> <초대코드> [관리자아이디 관리자비밀번호]
  ```
- 로그인·가입은 접속자별로 분당 10회까지만 받습니다.
- 사용자의 AI 키는 암호화해서 보관하고, 화면에는 끝 4자리만 보여줍니다.

## 개발하기

```bash
python3 tools/check_css.py            # CSS 중괄호 짝 검사 (하나만 빠져도 뒤 CSS가 전부 무너진다)
npm --prefix frontend run build       # 운영 빌드 — 경고까지 읽을 것
```

화면은 개발 서버보다 **운영 빌드**로 확인하세요. 개발 서버는 CSS를 파일마다 따로 넣어서, 운영 빌드에서만
생기는 문제를 보여주지 않습니다.
